Genera un perfil longitudinal y pendientes (%) a partir de una capa de líneas (ejes) y un DEM (raster local o WCS).

ENTRADAS

• Capa de líneas: eje o ejes a analizar. • DEM: raster de elevación (local o WCS). • Campo ID (opcional): identificador a conservar en salidas. • Intervalo de muestreo (m): distancia entre muestras. 0 = resolución del DEM. Recomendado: mínimo tamaño de píxel ×3. • Invertir sentido: cambia el origen del perfil (inicio ↔ fin).

SALIDAS

• Tabla (sin geometría): una fila por muestra con distancia, cota (RAW), cota suavizada, pendiente (%) y SLOPE_TYPE (REAL/INTERP/EXTRAP/NODATA). Esta tabla puede graficarse de modo sencillo con el algoritmo Profile Slope Plotter de L-RAT. • Capa segmentada (líneas): micro-tramos entre muestras con atributos de cota y pendiente para salidas gráficas cartográficas.

OPCIONES AVANZADAS

• Muestreo del DEM: Nearest / Bilineal / Cubico. • Suavizado: Ninguno / Media móvil / Mediana móvil / Savitzky-Golay (ventana y orden). • Usar M (si existe): añade PK a la tabla (km y formato km+mmm).

CONSEJOS

• Para pendientes coherentes, usa datos en un CRS proyectado (metros). • Si el DEM es ruidoso: prueba Mediana móvil o Savitzky-Golay y/o aumenta el paso.
