Genera, a partir de una tabla/dataset, los gráficos de:   • Perfil longitudinal   • Perfil + pendiente (%) Está diseñado específicamente para graficar las tablas generadas por el algoritmo «Slope and Longitudinal Profile» de este mismo propio plugin, aunque puede usarse con cualquier tabla compatible. El perfil siempre se representa contra la distancia real en metros (Dist_Origen_metros), pero permite elegir cómo etiquetar el eje X:   • PK (K+MMM) usando m_field_PK_KM (si hay valores faltantes, se interpolan/extrapolan para mantener marcas coherentes).   • Distancia usando Dist_Origen_metros (etiquetado en metros o km con intervalos lógicos). Se genera un par de gráficos por cada ID.

ENTRADAS

• Tabla/capa de entrada: dataset sin geometría (o capa) con distancia, cota y pendiente, normalmente salida directa del algoritmo «Slope and Longitudinal Profile». • Campo ID (opcional): identificador para separar perfiles y generar un gráfico por ID. • Campo X: distancia desde el origen (m). • Campo Y: cota del perfil (p. ej. Cota_SUAV). • Campo pendiente (opcional): pendiente en %. • Usar PK en el eje X (opcional): etiqueta el eje X como PK si existe el campo correspondiente. • Campo PK (opcional): PK en km (float). Si hay valores faltantes, se interpolan/extrapolan para generar marcas coherentes. • Mostrar etiquetas de ejes (opcional): si se activa, se muestran títulos y nombres de ejes (traducibles). Si se desactiva, no se muestran etiquetas ni títulos (los ticks conservan unidades).

SALIDAS

• Carpeta: contiene los PNG generados por ID (perfil y perfil + pendiente). • HTML Report: informe con vista previa y enlaces a todos los gráficos generados. Check Processing Toolbox > Results Viewer
