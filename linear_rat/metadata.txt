about=This Processing plugin adds a set of practical tools to the QGIS Processing Toolbox for working with linear features, especially in road and linear infrastructure projects. L-RAT focuses on linear referencing using PK/M values on calibrated LineStringM and MultiLineStringM geometries, allowing users to locate points and extract segments along linear networks, either manually or from attribute tables. The plugin also includes additional utilities for analysing linear data that do not require M geometry but are commonly needed in road engineering workflows such as curve/center detection and slope & longitudinal profile extraction from a DEM.
